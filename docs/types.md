## 1. 해시 (Kit 5 / 빈도 높음)

**Kit 이정표:** 폰켓몬, 완주하지 못한 선수, 전화번호 목록, 의상, 베스트앨범

**과정**

1. “같은 키를 몇 번 봤는가”로 바꾸는지 확인합니다.
2. `Counter` 또는 `defaultdict(list)`를 만듭니다.
3. 한 번 순회로 정답을 뽑습니다. 이중 루프는 보통 오답입니다.
4. 전화번호 목록처럼 접두어면 정렬 후 이웃만 비교하거나, 트라이를 생각합니다.

**파이썬:** `from collections import Counter, defaultdict`

**함정:** `dict` 키에 list를 쓰지 말 것. 미완주 1명은 `subtract` 후 값이 1인 키.

**다른 답:** 정렬 두 배열을 투 포인터로 비교.

---

## 2. 스택/큐 (Kit 6 / 점수 높음)

**Kit 이정표:** 같은 숫자는 싫어, 올바른 괄호, 기능개발, 프로세스, 다리를 지나는 트럭, 주식가격

**과정**

1. 꺼내는 순서가 LIFO면 스택, FIFO면 큐입니다.
2. 파이썬 스택은 `list.append/pop`. 큐는 반드시 `deque.popleft()`.
3. “앞이 끝나야 뒤가 나간다”면 큐에 남은 시간을 넣습니다.
4. 주식가격처럼 오큰수/오작수는 스택에 인덱스를 넣습니다.

**함정:** `list.pop(0)`은 O(n)이라 큐로 쓰지 않습니다.

**다른 답:** 기능개발은 큐 없이 배포 기준일을 갱신하며 카운트.

---

## 3. 힙 (Kit 3)

**Kit 이정표:** 더 맵게, 디스크 컨트롤러, 이중우선순위큐

**과정**

1. 매번 최솟값/최댓값이 필요하면 힙입니다.
2. `heapq`는 최소 힙만 있습니다. 최대 힙은 `-x`를 넣습니다.
3. 디스크 컨트롤러는 “현재 시각에 가능한 작업 중 가장 짧은 것” → 대기 힙.
4. 이중우선순위큐는 두 힙 + 삭제 카운터, 또는 `sortedlist`가 없으면 신중히 동기화.

**함정:** 빈 힙에서 `heappop` 하면 터집니다. 섞기 전에 길이 2 이상인지 봅니다.

---

## 4. 정렬 (Kit 3 / 빈도·점수 높음)

**Kit 이정표:** K번째수, 가장 큰 수, H-Index

**과정**

1. 비교 기준을 `key=`로 옮길 수 있는지 봅니다.
2. 가장 큰 수는 문자열 비교 `x+y > y+x`가 핵심입니다. `cmp_to_key`를 씁니다.
3. H-Index는 정렬 후 “인용 >= 편수”가 되는 최댓값을 이분하거나 한 번 순회합니다.

**함정:** 숫자 정렬과 문자열 정렬을 섞지 말 것. `[0, 0]` → `"0"`.

---

## 5. 완전탐색 (Kit 7 / 빈도 높음, 점수 낮음)

**Kit 이정표:** 최소직사각형, 모의고사, 소수 찾기, 카펫, 피로도, 전력망 둘로 나누기, 모음사전

**과정**

1. n이 작은지 확인합니다. 8~10이면 순열, 20이면 비트마스크/백트래킹.
2. `itertools.permutations / combinations / product`를 먼저 씁니다.
3. 소수 찾기는 만든 수를 `set`에 넣어 중복을 없앱니다.
4. 카펫은 약수 쌍만 보면 됩니다. 격자 전체를 돌 필요가 없습니다.

**함정:** 순열 폭발. 방문 배열 없는 재귀는 무한 루프.

**다른 답:** 피로도는 `permutations` 대신 DFS + 방문 비트.

---

## 6. 탐욕법 (Kit 6 / 빈도·점수 낮음)

**Kit 이정표:** 체육복, 조이스틱, 큰 수 만들기, 구명보트, 섬 연결하기, 단속카메라

**과정**

1. “지금 이 선택이 뒤도 망치지 않는가”를 한 줄로 말합니다. 못하면 그리디가 아닙니다.
2. 보통 **정렬 후 한 방향 스캔**입니다.
3. 구명보트는 가장 무거운 사람과 가장 가벼운 사람을 짝 → 투 포인터.
4. 섬 연결하기는 크루스칼(MST)입니다. 그리디 + 유니온 파인드.
5. 단속카메라는 진출 시점 정렬.

**함정:** 조이스틱은 단순 그리디가 깨지는 케이스가 있습니다. 좌우 이동을 모두 시뮬해야 합니다.

---

## 7. 동적계획법 (Kit 5 / 점수 낮음)

**Kit 이정표:** N으로 표현, 정수 삼각형, 등굣길, 사칙연산, 도둑질

**과정**

1. “상태”를 말로 정의합니다. 예: `dp[i][j] = i행 j열까지 오는 최댓값`.
2. 점화식과 초기값을 적습니다.
3. Bottom-up 배열이 디버깅이 쉽습니다. 메모이제이션은 상태가 희소할 때.
4. 등굣길은 장애물을 0으로 두고 왼쪽+위.
5. 도둑질은 원형 → “첫 집 포함/제외” 두 번 선형 DP.

**함정:** 모듈러, 경로 0 나눗셈, 인덱스 off-by-one.

**다른 답:** 정수 삼각형은 위에서 내려가는 것보다 아래에서 올라가는 쪽이 배열이 단순합니다.

---

## 8. DFS/BFS (Kit 7 / 빈도 높음, 점수 낮음)

**Kit 이정표:** 타겟 넘버, 네트워크, 게임 맵 최단거리, 단어 변환, 아이템 줍기, 여행경로, 퍼즐 조각 채우기

**과정**

1. **최단 거리·최소 횟수 → BFS.** 모든 경로·조합 → DFS/백트래킹.
2. 그래프를 인접 리스트로 바꿉니다. 격자면 4방향 델타.
3. BFS는 `deque`, 방문 체크를 큐에 넣을 때 합니다.
4. 여행경로는 “사전순 오일러 경로” → 도착 공항을 정렬해 두고 Hierholzer.

**함정:** DFS로 최단거리를 구하면 틀립니다. 파이썬 재귀 한도는 `sys.setrecursionlimit`보다 반복 DFS가 안전합니다.

---

## 9. 이분탐색 (Kit 2)

**Kit 이정표:** 입국심사, 징검다리

**과정**

1. 값이 정렬되어 있거나, “시간이 t일 때 가능한가?”가 단조이면 이분탐색입니다.
2. **이분 대상은 인덱스만이 아닙니다.** 정답 자체(시간, 거리)를 이분합니다.
3. `mid`가 가능하면 `hi = mid`, 아니면 `lo = mid + 1`.
4. 입국심사는 `sum(mid // time for time in times) >= n`.

**함정:** `lo, hi` 범위. `max(times) * n`이 상한. 중간에서 오버플로는 파이썬에선 드뭅니다.

**다른 답:** `bisect_left`는 “정렬된 배열에서 위치”용. 파라메트릭 서치는 직접 루프가 읽기 쉽습니다.

---

## 10. 그래프 (Kit 3)

**Kit 이정표:** 가장 먼 노드, 순위, 방의 개수

**과정**

1. 간선 리스트 → 인접 리스트. 양방향인지 확인합니다.
2. 가장 먼 노드: 1번에서 BFS 거리 → 최댓값 개수.
3. 순위: 승패를 방향 그래프로 두고 Floyd 또는 DFS로 전후 관계를 닫습니다. 다른 전원과 비교 가능하면 순위 확정.
4. 방의 개수는 좌표를 2배 해서 대각선 교차점을 격자 점으로 만드는 구현에 가깝습니다.

**함정:** 노드가 1-based. 방문 배열 크기 `n+1`.

## 11. Kit 밖 — 구현·시뮬레이션 (삼성)

**과정:** 문제에서 시키는 대로 격자를 돌립니다. 회전은 `zip(*grid[::-1])`. 턴마다 복사본을 만들지, in-place로 할지 먼저 정합니다. DFS/BFS는 “이동 규칙”이 정해진 뒤에 붙입니다.

## 12. Kit 밖 — 문자열 (카카오)

**과정:** 토큰 분리 → 스택/재귀로 중첩 처리 → 숫자·문자 변환. `re`는 실수 지점이 많아서, 코테에선 포인터로 파싱하는 편이 안전합니다.

## 13. Kit 밖 — 투 포인터 / 슬라이딩 윈도우

**과정:** 정렬된 배열의 합, 연속 부분 수열, 고정 길이 최댓값. 왼쪽을 움직이면 오른쪽도 단조로 움직입니다. 윈도우는 `current += in - out`.

## 14. Kit 밖 — 최단경로·유니온 파인드

- 가중치 양수 최단경로: `heapq` 다익스트라.
- 모든 쌍: Floyd-Warshall, n≤400.
- 네트워크 연결/사이클: 유니온 파인드 (경로 압축 + rank).
- MST: 크루스칼 = 정렬 + 유니온 파인드.

## 15. Kit 밖 — 백트래킹·비트마스킹·수학

- 백트래킹: 넣고 → 재귀 → 빼기. 가지치기를 먼저 적습니다.
- 비트마스크: 방문 집합이 n≤20일 때 `visited | (1 << i)`.
- 수학: 소수(에라토스테네스), 조합 수, 최대공약수 `math.gcd`.

## 파이썬 치트시트

```python
from collections import deque, Counter, defaultdict
import heapq, bisect, math, sys
from itertools import permutations, combinations, product

sys.setrecursionlimit(10**6)  # 가능하면 반복문이 더 안전
```

| 목적 | 함수 |
| --- | --- |
| 빈도 | `Counter` |
| 큐/BFS | `deque.popleft` |
| 힙 | `heapq.heappush/pop` |
| 이분 | `bisect_left` |
| 순열조합 | `itertools` |
| 무한 | `float("inf")` |
| 2차원 초기화 | `[[0]*m for _ in range(n)]`  ← `[[0]*m]*n` 금지 |
